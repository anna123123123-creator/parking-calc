# 停车费计算器 · Parking Fee Calculator

**[在线体验 →](https://anna123123123-creator.github.io/parking-calc/)**

免费开源、纯浏览器运行的停车费计算工具。输入入场、出场时间和计费规则（免费时长、首小时费率、续时费率、每日封顶），自动按阶梯计费算出应付停车费。纯前端计算，不联网。

![screenshot](screenshot.png)

## 试用方法

直接用浏览器打开 `index.html`，或用静态文件服务器跑起来：

```bash
python3 -m http.server 8000
```

## 计费规则

- 停车时长在"免费时长"内 → 免费
- 超出免费时长 → 首小时按"首小时费用"计费，之后每小时（不足一小时按一小时算）按"续时每小时费用"累加
- 每 24 小时应用一次"每日封顶"，跨天停车按自然 24 小时窗口简化估算
